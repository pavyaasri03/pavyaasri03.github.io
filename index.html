First, make the answer
traceable to the source.

A long document is not a ready-made question bank. I built the path from source material to assessments that teachers can review.

The decision: generation was one stage, not the finish line. I used chunked map-reduce extraction and a generation → verification → repair flow, with teachers reviewing the result.

The result: a quiz-generation workflow validated on a 98-page source, with deterministic objective scoring, bounded AI descriptive grading, and tenant-scoped queries backed by isolation tests.

The problem +

Large sources need faithful extraction before question generation. Assessments also need scoring boundaries and separation between tenants.

Inside the implementation +

Next.js and TypeScript connect the product interface to FastAPI/Python workflows. PostgreSQL/Supabase store tenant-scoped records; DeepSeek and Gemini support the model workflows. Verification and repair sit between generation and teacher review.

02 / LINGOCUTMULTILINGUAL AI · SPEECH PIPELINES

Translation is text.
A voice needs timing.

Turning English lectures into colloquial Indian-language audio meant working with meaning, missing speech and the length of every segment.

The turning point: I traced missing speech to a lossy sentence parser. Round-trip checks helped verify that the text entering the pipeline survived the transformation.

The result: dubbing and editable voiceover workflows supporting 12 code-switched dialects, with Gemini Live/TTS, FFmpeg time fitting, retries and checkpoints.

Inside the implementation +

Processing at segment level made timing explicit. Editable translations gave people a correction step, while retries and checkpoints let interrupted processing resume without discarding the entire workflow.

03 / MARKETINSIGHT PROLLM CLASSIFICATION · INTELLIGENCE

More mentions.
Less noise.

Marketing signals arrive from different sources with different formats and failure modes. The useful part is the context you can trust.

The decision: separate collection, classification and response drafting. I orchestrated LLMs for relevance and sentiment, with source-grounded replies passing through human review.

The result: daily trend rollups across 8+ sources, supported by serverless API proxies, retries and per-source failure reporting.

Inside the implementation +

React and TypeScript power the interface; Firestore stores the workflow data. Groq, Gemini and Claude support classification and drafting. Explicit collection errors make it clear when a source fails instead of silently presenting an incomplete picture.
